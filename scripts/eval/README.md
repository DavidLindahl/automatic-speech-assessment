# `scripts/eval/` — Model Evaluation and Analysis

This directory contains scripts for evaluating trained models and baseline LLMs on global speech quality and temporal localization tasks.

## Scripts

- **`evaluate.py`**: Evaluates model performance on the global MOS-captioning task, computing metrics such as Pearson correlation (\(r\)), Spearman correlation (\(\rho\)), Mean Squared Error (MSE), and Mean Absolute Error (MAE).
- **`evaluate_temporal.py`**: Evaluates temporal localization capabilities using metrics like temporal Intersection-over-Union (t-IoU) at various thresholds, precision/recall, and caption BLEU scores.
- **`evaluate_gemini_mos.py`**: Evaluates zero-shot or few-shot Gemini models on global MOS-captioning.
- **`evaluate_gemini_temporal.py`**: Evaluates Gemini on temporal localization tasks.
- **`gemini_temporal_caption_bleu.py`**: Specifically calculates BLEU scores for temporal captions generated by Gemini.
- **`analyze_global_task.py`**: Analyzes and aggregates metrics for the global MOS-captioning tasks.
- **`rescore_temporal_table.py`**: Helper script to post-process raw temporal evaluations and format results into LaTeX/Markdown comparison tables.
